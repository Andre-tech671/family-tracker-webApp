# Family Travel Tracker

A web application to track family travels using Node.js, Express, and PostgreSQL.

## Features

- Add new family members
- Record travel destinations
- View all travels

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/Andre-tech671/family-tracker-webApp.git
   cd family-tracker-webApp
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Set up PostgreSQL database and run the queries in `queries.sql` to create tables.

4. Start the server:
   ```
   npm start
   ```

5. Open your browser to `http://localhost:3000`

## Technologies Used

- Node.js
- Express.js
- PostgreSQL
- EJS for templating
- CSS for styling
